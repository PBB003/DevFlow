# DevFlow

DevFlow is a full-stack web application designed to help developers organize tasks, track learning progress, and reflect on what they improve over time.  

This project is part of my personal journey toward becoming a stronger full-stack developer. It focuses on clean code, real-world workflows, and good development practices.

---

## Features (planned)

- Task management (todo, in progress, done)
- Notes for technical learning
- Progress timeline and activity tracking
- Tags and filters
- Authentication (later)
- Analytics dashboard (later)

---
